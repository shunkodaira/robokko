# 黒猫タコ（A1 mini向け改造外装）

おばけねこの中身（ATOM S3R、SG90、ヒンジ、ソケット）はそのまま使って、外側だけ黒猫とタコ足にしたものです。参考画像の丸い頭をそのまま削り出したデータではありません。印刷できる形に置き換えています。

このデータは、なかよしロボティクス「ロボっこ」（企画・デザイン：ハヤカワ五味／設計・3Dデータ：uni）を元にした非営利の改造です。
元データ：https://github.com/hayakawagomichan/robokko
営利販売はできません。個人利用と、自分で使う部品の印刷代行は、元の利用条件どおりです。

## 組み立て

配線・ホーンの角度・ヒンジの接着は、おばけねこの説明書と同じです。違うのは外装だけです。

1. ソケットに ATOM S3R、SG90、Grove を入れ、ヒンジを純正どおり固定する。
2. ソケットを頭の裾から入れ、画面を正面の四角い穴に合わせる。穴は約 24.2 mm。ATOM S3R の面は 24.0 × 24.0 mm なので、ガラスは軽く押せる位置になります。強く押し込むと割れます。
3. コードを動く部分に挟まないよう隙間へ入れる。
4. タコ足を、純正の足と同じ向きで裾にはめる。USB給電ならスペーサー、バッテリーなら ATOMIC Battery Base（A151）です。
5. 全体を起こす。
6. ひげは細い方を穴に差し、頬に3本ずつ接着する。きつければ軸を少し削る。
7. しっぽの軸を、向かって左後ろの穴に差す。接着前に回して、カーブが上に向く位置で固定する。穴は直径 8.4 mm、軸はそれより細くしてあるので、瞬間接着剤かボンドで埋めます。

画面を1回押すと往復、もう1回で停止、というのは純正と同じです。

## 参考画像との違い

- 頭の外側は、おばけねこのベル形に耳・頬・しっぽ受けを足した形です。写真のようなまん丸の頭ではありません。中を新しく彫ると、24 mm の画面穴とソケットの 0.2 mm ほどの隙間が崩れるためです。
- ひげは頭と別部品です。ほぼまっすぐで、先が細くなります。
- しっぽは一平面のカーブです。立てる角度は接着のときに合わせます。
- タコ足の裏はプレートに付く平面です。先は上に反りません（反らすとサポートが要るため）。裾の下を高さ約 3.3 mm のタブがくぐり、裾の外で太くなります。
- 純正の小さな足先より接地面が広いので、机の上では安定します。サーボが唸る、ATOM が再起動する、というときは電源を切り、タコ足の裏を軽く削って接地面を減らしてください。
